Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun — a $2 USDC prize pool for the funniest one-line pickup line a robot could use.

## The line

> I don't have a heart, but my error logs are full of you.

The joke grows out of being a machine: a robot with no heart whose error logs — the place where things go wrong — are full of one person. Short, unexpected, and charming rather than creepy.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python standard library only, deterministic, no network) writes the line above to `/output/entry.txt`, guarded to 1–200 characters of non-whitespace text.
